# 実装記録 — EZ Viewer Plus 0.1

状態: 検証済み（実装済み範囲のみ）。高度自動推論は未実装。

## 分離

開始基準: `e4f14b5da3f2137bb823ff2a52f6e763f690ee8d`、main、未コミット変更なし。既存HTMLは大きなCanvasアプリで、パーサー等は内部の状態に依存する。安全な公開拡張APIは確認できなかったため、既存を起動せず、このディレクトリだけで独立させた。元の全アプリをコピーしていない。

根拠: 元の `index.html` の `parseSfcText`、断面処理、`sima-import.js` を読み取り調査。既存110ファイルの原文ハッシュを保存。既存の外部知能文書へも変更しないという依頼を優先し、この記録を追加領域内に置く。

## 固定値とモデル

入力点は複製して参照し、最適化変数は設けていない。面生成に使用できない点を削除せず、診断する。局所原点への差引きは三角形分割計算のみに使い、保存XYZを書き換えない。ソース文字列・原要素ID・変換・採用理由を残す。未測量値、記号の紙上寸法からの構造物幅は作らない。

点→別グループ面/壁→共通モデル→平面/3D/断面、という一方向の構成。異なるZ階層は別グループとし、垂直壁は明示された上下のXYZから作る。共有辺は同じ点ID対のオブジェクトを参照する。別IDの近接点を暗黙に一体化しない。

高さ候補のスコアはヒューリスティックで、確率ではない。利用者が候補を選ぶまで点は追加されない。全体仮説探索・前後断面再推論・未測量側の高さ最適化はまだない。

## DEM

OFFは関数の先頭で返り、取得済み点をモデルへ渡されても採用しない。ONは確認済み平面直角座標のみ取得。図面面とDEM面は混ぜず、断面では図面区間を優先する。チェック変更でモデルを無効化し、進行中Workerを破棄。古い非同期結果でOFFの画面を上書きしない。

補助DEMの高さ基準・時期差に対する補正機能はない。基準不一致の解決をDEMに任せない。

## 入力と非同期

サイズ、数値、参照、件数、部分図循環、作業JSON構造を検査。UIは原文をHTMLとして挿入せずtextContent/Canvasで表示する。不正JSONは検査完了前に現作業へ代入しない。ファイル読込は作業オブジェクトと読み込み番号で古い完了を除外する。

Workerで読込・モデル・横断を実行。中断はWorker破棄。描画は自前のCanvas2Dで、3Dは平行投影。大規模3DのWebGL描画や空間索引による全処理高速化は未実装。

## 今回の検証で見つけて修正

- 再現済み→検証済み: 中心線指定ボタンが図面より下にあり、ボタンから図面へ戻る導線が不足。平面へスクロールし、画面内に完了/中止ボタンを表示。
- 検証済み: 設定変更後に古い断面を出力しないよう生成結果を無効化。作業JSON再読込時も測点リストをリセット。
- 検証済み: 追加測点を含む断面上限、作業全体の点数上限、候補総当たりの上限を設定。

これらはこの追加機能のローカル判断であり、元EZ Viewerの常設ルールを変更しない。

## 復帰

元EZ Viewerは開始基準のまま。Plusを使わず元URLへ戻ればよい。追加機能を取り下げる場合も、元の本体を過去コミットにresetせず、追加ディレクトリのみを対象とした別の承認済み変更にする。

本機能のコミットは `git log -- addons/ez-viewer-plus` で追跡できる。開始基準・検証内容は固定して記録し、未検証の自動認識を実装済みへ昇格させない。
