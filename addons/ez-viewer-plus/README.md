# EZ Viewer Plus — 現況3D・横断作成（独立試作版 0.1）

EZ Viewerに影響させず検証するための**独立した追加ページ**です。原作品の名称「EZ Viewer」を保持します。元のEZ Viewerの代替品でも、完全自動認識の完成版でもありません。

入口: [EZ Viewer Plus](https://iku190t.github.io/ais-survey-tool/addons/ez-viewer-plus/)

元のEZ Viewer: [従来どおりのURL](https://iku190t.github.io/ais-survey-tool/)

## 大切な点

- 「DEMを補助に使う」は初期状態 **OFF**。OFFでは図面だけで生成し、DEMの通信・キャッシュ参照・補完を行いません。高さが足りない場所は未確定のままです。
- ONでは指定範囲の国土地理院DEMを補助面として読みます。図面の点を変更せず、横断では図面由来の線が存在する区間にDEMを重ねません。DEMを細かく補間しても精度が高くなったことにはなりません。
- **標高文字とプロットの対応、点が属する面、中心線は利用者による確認が必要**です。AIによる道路・側溝・擁壁の完全自動認識はまだありません。
- 実測確認済みXYZは数値を変更しません。未確認のSIMA、図面文字からの復元、面からの補間、DEMを別の出所として扱います。小数表示桁数は精度を意味しません。
- **この版は自動保存しません。終了前に「作業JSONを保存」してください。** JSONを開けば、入力・採用対応・面の設定・中心線を再現できます。生成結果は再計算します。DEMは作業JSONに保存せず、ONの生成時に再取得します。
- SFC等の元ファイルへ上書きしません。元のEZ Viewerの保存領域にもアクセスしません。
- 実地で正解と比較した精度検証は未実施です。成果品の自動作成・測量精度の保証には使わず、まず比較検証用として扱ってください。

## 試し方

### まず合成例で確認

1. 「合成例で試す」を押します。道路・高低の地盤・垂直壁・情報不足の隙間が表示されます。現地の実測データではありません。
2. 「3D」で回転表示、「横断」の測点で10mごとの切断結果を確認します。
3. 断面線を押すと、その面の参照点・原要素IDを確認できます。
4. 「全断面CSV」「表示断面SVG」「モデル・根拠JSON」で出力できます。
5. この合成例の座標は仮想です。実際のDEMとは対応しないため、実地図との精度比較には使用しないでください。

### 図面だけで作る

1. SFC / SIM / SIMAを選択します。複数ファイルは同じ作業へ追加します。
2. 単位・解析部分図・座標の方向を確認します。内部計算はm、平面表示の横軸は東（測量Y）、縦軸は北（測量X）。SIMAはm、SFCは初期mm→mです。
3. SIMAのZがある点はそのまま使用できます。「実測確認済み」をONにして読み込んだ点のみ、その出所ラベルになります。Zが空欄の点は高さ不明です。
4. SFCの場合は「プロットと標高文字の候補を見る」で対応を確認して採用します。点番・寸法と標高を混同しないでください。プロット中心をXYに使用し、文字の位置を測点にはしません。
5. 所属点を平面で選択するか点名を入力し、面を追加します。異なる高さ階層・地物は別の面にします。カンマを含む点名や同名点は、点一覧/JSONの一意な点IDを指定してください。
6. 必要なら上端・下端の高さ付き点を対応順に指定して擁壁面を追加します。未測量側の高さを自動で作りません。
7. 「中心線を平面で指定」で進行方向に点を押し、「指定を完了」。10m、20m等のピッチ、片側幅、任意の追加測点を入力します。
8. **DEMをOFFのまま**「3D・横断を生成」。検査欄と未確定区間を確認してください。

### DEMを補助にする

「DEMを補助に使う」をONにし、平面直角座標の系を選び、現場の座標であることを確認して生成します。用紙座標・任意座標・仮想座標のまま使ってはいけません。水平座標はJGD2011/JGD2024系のGRS80平面直角座標を想定し、異なる測地系への時点補正や標高基準の変換は行いません。図面の標高基準とDEMの標高基準・整備時期の差は利用者が確認する必要があります。

標高タイルはDEM1A→DEM5A→DEM5B→DEM5C→DEM10Bの順に有効画素を探します。取得は中心線周辺1km²以内、最大96タイル、サンプル間隔は5m以上で範囲に応じて粗くなります。1mメッシュの元データがあっても、この版が1m間隔で面を生成する意味ではありません。通信失敗時に生成成功とは表示しません。欠測は隙間として残します。

## 対応範囲と限界

| 分野           | 今回動く内容                                                                   | まだ行わない内容                                                                          |
| -------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| SFC            | 線分、折線、円、円弧、点マーカ、文字、部分図/部品の配置変換。原SXFレコード保持 | スプライン、寸法、引出し線、ハッチング、外部参照の意味解析、全フィーチャ完全互換。SFZ/P21 |
| 部分図         | 解析する部分図を選択。部分図内のローカル座標を使用                             | 紙面上の配置から現場座標系を自動確定する処理                                              |
| SIMA           | A01座標と任意Z、D00/B01画地                                                    | 他の全レコードの意味解析、中心線設計データの自動認識                                      |
| 原情報         | デコード済み原文・要素ID・数値文字列・配置変換をJSONへ保持                     | 入力バイナリの完全再出力。表示用の円弧分割を実測線とは扱わない                            |
| 標高対応       | 複数候補を距離・文字方向・レイヤーで順位付けし、利用者が確定                   | 複合プロット全般、引出し線の強い証拠認識、全図の競合解消、校正済み確率                    |
| 地物           | 利用者が道路/地形/水路/橋面の所属点、擁壁上下を指定                            | 地物の意味・作図過程・CADオフセットの自動認識                                             |
| 面             | 別グループごとの三角形面、壁、共有境界、同じXYの別階層                         | 一意に決まらない側溝底等の推測、全体最適化、複数仮説の探索                                |
| ブレークライン | 線を跨ぐ三角形を除外。線が面の辺にならない場合は診断と隙間                     | 完全な制約付きDelaunay。必ず指定線に沿った面ができるわけではない                          |
| 接続検査       | 微小線・近い端点の候補提示。原線は不変                                         | はみ出し・重複・文字避け切断の包括的意味判定、自動接続修正                                |
| 横断           | 共通モデルを任意ピッチ/追加測点/斜交角で切断。情報不足の間をつながない         | 円曲線・緩和曲線の厳密な設計線形、縦断図、成果品用図枠・SFC/DXF出力                       |
| 追加測量       | 断面の未確定範囲と、測る対象の違いを表示                                       | 感度解析、観測位置の最適化、精度の数値保証                                                |

中心線は折線です。折点そのものでは進入側の接線で切断し、画面に表示します。曲線を折線として指定する場合は近似です。進行方向の左側を正の離れとし、横断画面は数値軸として右に正を描くため「−右側 / 左側＋」と表示します。SVGは表示用で、縦横の倍率は別です。

対象点が面の頂点に反映されなかった場合は「面に未反映」と検査欄に出ます。最大辺長、点の不足、同一XYの矛盾、除外範囲を確認してください。同じ面内の相反する高さを平均して解決しません。

境界付近や穴を含むデータは、最大辺長・除外範囲・面分割を必ず確認してください。Delaunayは点の間を補間するもので、図面の全ての境界や構造物の意味を理解していません。

## 保存・プライバシー・既存保護

- SFC/SIMAと作業JSONはブラウザ内で処理。外部AI・サーバーへファイルを送信しません。
- DEM ONで生成したときだけ、該当位置のタイル番号を国土地理院へ送信します。元ファイル名や原文は送信しません。
- 外部CDNなし。ライブラリはこのフォルダーに同梱。Service Worker、localStorage、IndexedDB、Cache Storageは使用しません。
- 同じGitHub Pagesドメインの別パスです。別ドメインというセキュリティ隔離ではありませんが、元アプリを起動・参照せず、ストレージを利用しない方式で独立させています。
- `PROTECTION_BASELINE.json`は着手時の追跡対象110ファイルのSHA-256。`node scripts/protect-existing.mjs verify`で元ファイルの変更・追加領域外の変更を検出します。
- 作業JSONは入力原文や座標を含みます。顧客データを含むJSONを公開リポジトリ等へ置かないでください。

## ローカル起動・開発

このフォルダーで、Node.js 20以上を使って実行します（動作確認はNode.js 24）。依存コードは同梱済みです。

```sh
node scripts/serve.mjs
# http://127.0.0.1:4173/addons/ez-viewer-plus/
node --test tests/core.test.mjs
node scripts/protect-existing.mjs verify
```

ブラウザ試験はPlaywrightが解決できる環境で `node tests/browser.cjs`。Chromeのパスは `CHROME_PATH`、公開URLは `BASE_URL` で上書きできます。既存リポジトリの依存管理は変更しません。ライブラリを再配置する場合だけ、この追加フォルダーで `pnpm install --frozen-lockfile --ignore-scripts` → `node scripts/vendor.mjs`。

主な構成: `index.html` / `styles.css` / `app.mjs` / `views.mjs` / `worker.mjs`、`core/`（読込・根拠・幾何・面・DEM・保存）、`fixtures/`（合成例）、`tests/`、`scripts/`、`vendor/`、`docs/`。
