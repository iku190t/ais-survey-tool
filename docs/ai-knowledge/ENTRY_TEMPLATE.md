# 外部知能エントリーテンプレート

以下をコピーして、該当文書へ追加する。空欄を推測で埋めない。

```markdown
## <ID> <短い題名>

- 日付: YYYY-MM-DD
- 状態: 観察 | 再現済み | 検証済み | 廃止
- 対象機能:
- 対象環境: PC | Android | iPhone | 共通
- 基準ブランチ:
- 基準コミット:

### 観察

何が起きたか。ユーザー報告と実測を分けて書く。

### 再現手順

1.
2.
3.

### 仮説

未検証なら必ず「仮説」と明記する。不要なら削除。

### 根本原因

再現・コード・仕様書・正常ファイルで確認できた原因だけを書く。

### 判断

採用した仕様と、採用しなかった案・理由。

### 修正範囲

- 変更ファイル:
- 変更した関数/領域:
- 変更禁止・非対象:

### 検証

- 実行コマンド:
- 結果:
- 実データ確認:
- 残る制限:

### Git

- 修正コミット:
- 正常基準:
- 戻し方:

### ルール昇格

- 独立した確認回数: 1
- 常設判断へ昇格: いいえ
```

## 記録前チェック

- [ ] 会話だけでなく証拠がある
- [ ] 観察・仮説・確定原因を分けた
- [ ] 個人情報、秘密、顧客データを書いていない
- [ ] 変更していない機能を「確認済み」と書いていない
- [ ] テスト失敗を隠していない
- [ ] コミットと戻し先を書いた
- [ ] 同じ知見が2回未満なら常設ルールへ昇格していない
