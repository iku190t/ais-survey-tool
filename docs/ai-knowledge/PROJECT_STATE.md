## 現在の重要な動作方針

- DEMを使う標高処理はDEM1Aを先に使い、欠損点だけDEM5Aで補う。
- 等高線CAD化では表示倍率で精度を落とさず、DEM1A優先の1m格子を基準にする。
- 表示だけの操作は復元用データ保存を行わない。レイヤー色、手書き、写真など実データ変更は保存対象。
- 前回作業の復元は、元SFCの端末内複製と編集差分を分離する。元SFCは図面ごとに1回だけIndexedDBへ保存し、通常の編集では差分だけを更新する。元JPEGはブラウザ再起動後に再接続が必要な場合がある。
- スマホの方位追従は現在地/GPSとは独立する。ファイル読込時には方位許可を要求せず、方位ボタンを押した時だけ追従を開始する。再押下で停止し、ホーム操作は追従を停止して読み込み時の角度へ戻す。
- PCの写真ドラッグ＆ドロップは、位置情報付き写真が1枚以上正常に読めた時だけ旧写真一式を置換する。写真選択ボタンは追加・統合動作を維持する。
- ブラウザの `File` は永続化できないため、同じ起動中は直接参照を保持し、再起動後に元JPEGが必要な処理では再接続が必要になり得る。
- Web Geolocation APIだけではDroggerのRTK FIX/FLOAT状態を独立して判別できない。一般Web版は従来どおり水平誤差を表示し、専用Android版だけ端末内NMEA GGAからFIX/FLOATを表示・記録する。どちらもFIXを登録条件にせず、利用者が登録可否を判断する。標高は楕円体高をそのまま使わず、端末へ保存した公式ISGモデルのジオイド高と入力アンテナ高を差し引く。
